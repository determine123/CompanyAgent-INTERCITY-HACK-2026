# CompanyAgent v0.9｜问题驱动、可验证、可回滚的企业 Agent 工作台

## 产品定位

CompanyAgent 是员工用自然语言提出真实业务问题、使用授权业务工具交付结果，并通过执行反馈持续改进的企业 Agent 平台。**以解决业务问题为主，而非堆砌 Agent 数量。**

业务主流程：`业务问题 → Agent/Skill → 已授权数据 → 工具执行 → 质量验证 → 反馈/缺陷 → 改进实验 → 所有人审批 → 策略版本发布 → 新任务验证/回滚`。

本版实际支持的是 **户外媒体投放提案领域**；不能把它宣传为已经解决任意企业工作流。

## 现在可演示的场景

### 场景 A：企业员工自建 Agent

员工打开「我的 Agents」，描述：“食品饮料客户需要500万元广告方案，希望基于正大广场周边覆盖证据自动选线并调整预算”。按“从业务问题创建 Agent + Skill”后，平台创建私人 Agent 和 Skill，自动绑定白名单中的解析、库存、覆盖、预算、风险和解释工具。员工转到任务工作台即可运行。

该构建器目前是**行业限定模板**，不是 LLM 自动编写代码或安装未知 Skill。

### 场景 B：从失败中迭代

使用授权比赛资料和公司提供的三个商圈覆盖 CSV；在「智能任务执行」选择默认 Agent、正大广场、500万元、暂时取消严格覆盖筛选。运行任务时质量检查发现一项媒体缺少正大广场覆盖证据，并自动生成待验证的改进建议。

在「自我迭代实验室」选择“运行对照测试”。平台使用相同的任务输入、相同数据集 ID，分别执行旧规则和候选规则，不改变生产状态。当前数据样例实测结果：旧规则13项媒体，其中1项缺证据，500万元；候选规则12项、0项缺证据、494万元。

实验通过后由 Skill 所有者/管理员点击“批准发布”，系统发布新的 `strict_coverage` 策略并保留版本。下次运行便自动过滤缺证据媒体。若策略造成意外后果，所有者可以点击“回滚”，审计记录不会删除。

**含义限定：**实测仅证明“覆盖证据一致性”改善，不代表真实触达人次、2027年库存、正式价格或业务转化效果提升，也不等同全局最优。

## 数据能力与边界

- **可用：**人工授权导出的 CSV/XLSX；本机批准的导出文件目录监控；管理员白名单配置的只读 HTTPS 文件数据源。
- **未打通：**红豆系统、可视化平台未经确认的内部 API；无验证码绕过、网页密码自动抓取、未经许可的跨系统数据传输。
- **当前队内数据：**2026-11-13 历史公交库存 431 条；正大广场/上海南站/新天地覆盖导出 44 条；脱敏区间刊例（以原始数据有效字段为准）。地铁点位覆盖不等于地铁可售库存。
- **安全：**员工私有 Agent/Skill、服务端会话与 CSRF、工具白名单、反馈记录、操作审计、版本回滚。
- **未完备：**单租户本地 MVP，没有经过渗透测试，旧版 `/api/*` 缺乏完整身份保护，不适合直接暴露公网或承载企业生产数据。

## 迭代门禁

1. 自动检测质量问题或人工反馈，但不自动执行修改。
2. 目前只有一项可自动升级的白名单策略：**严格地标覆盖证据过滤**。
3. 对照实验必须通过：改进后缺证据候选数归零、预算不超支、仍有候选、质量指标严格改善。
4. 只有 Skill 所有者或管理员可发布；新版本对后续任务生效，历史结果不被悄悄覆盖。
5. 可一键回滚；版本冲突拒绝覆盖更新。
6. 其他需求（新 API、审批工作流、RAG、自动写代码）先作为人工反馈和后续开发任务，不虚构已经自主解决。

## 赛后演进方向（尚未实现）

- Pi SDK 或其他可替换 Runtime：多步骤规划、结构化工具调用和会话记忆。
- 针对新 Skill 的模板化生成、可读 Diff、测试用例自动生成、沙箱执行。
- 代码改进需进入隔离分支/PR，CI 安全与回归测试通过后由人审核部署；绝不允许生产 Agent 直接改写运行中的后端。
- 完整组织与数据权限：SSO、RBAC/ABAC、密钥保险库、Model Broker、MCP Policy Gateway、不可篡改审计。
- 正式企业 API 接入：由命题方授权提供接口文档及最小权限访问凭证，先在测试环境完成集成。

## 技术实现

FastAPI + SQLite + 原生 Web；确定性工具编排与预算约束优化，模型解释可选。新增模块 `enterprise/iteration.py`，`enterprise/api.py` 中的一键 Agent/Skill 创建入口，`enterprise/engine.py` 的 `strict_coverage` 运行策略。真实执行日志和 Agent 策略版本保存本机 `runtime/`，不能上传公共 Git 仓库。

## 运行与验收

```bash
python -m pip install -r requirements.txt
python server.py
```

浏览器访问 `http://127.0.0.1:8765/enterprise/`。管理员首次密码保存在本机 `runtime/FIRST_LOGIN.txt`，首次成功登录后自动清除。**请在登录后立即更换管理员密码。**

测试：

```bash
python -m pytest -q
python tests/browser_iteration_v09.py   # 需要 Playwright 和 Chromium，仅开发环境
```

新一轮测试：74/74 个后端测试、16/16 个专门的浏览器闭环检查通过。当前只在临时测试环境验证，不等同生产部署或公网可访问。
