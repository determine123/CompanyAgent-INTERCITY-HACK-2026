**状态：接口文档已收到；未获得公司正式接入审批，不存在任何真实数据读取、网络联通或库存验证结果。**

## 业务范围仅选择一个行业

本轮只针对 **食品饮料**：客户输入品牌、投放时间、100/200/500 万元预算、商圈、公交/地铁媒体偏好，Agent 输出**参考情景方案**与人工待确认问题。当前公开站点只用合成历史样例，不能声称可以预订或锁位。

## 数据接口事实与未知项

- **已提供合同式说明**：红豆媒体管理系统有两个独立的 GET 查询：公交车媒体库存、地铁出入口媒体库存。两者都使用分页和查询起止日期；公交可用 `lineName`，地铁可用 `keyword`；认证需要 `tenant-id` 与 `Authorization: Bearer ...`。
- **尚未提供**：响应 JSON 样例及每个字段定义、错误码与分页总量含义、可售/已锁位区分、账户数据范围、限流约束、企业数据保留规则、可用于试点的脱敏测试账号、网络来源白名单。
- **明确没有 API**：可视化/空间覆盖平台。不得虚构该服务或绕过网页登录抓取。覆盖证据目前只能使用**经授权的离线导出**，按源文件哈希与日期保留，并与库存分开展示。
- **公开代码禁止披露企业服务地址**：公开仓库 `enterprise/hongdou_contract.py` 仅包含不可解析的占位地址和接口请求参数契约；真实主机/路由/租户/令牌只能通过公司审批的私有配置下发。

## 分阶段联调

1. **合成契约测试（已可执行）**：`python -m pytest -q tests/test_hongdou_contract_v16.py`。断言仅 bus/metro、固定分页参数、日期窗口、参数过滤及未授权调用阻断。 `inspect_mock_response` 只看 JSON 结构、字段名和数组长度；**不能推断真实库存可售数量**。
2. **企业内网契约校验（待审批）**：在公司批准的隔离测试环境获取匿名化公交与地铁返回样例，先建立 JSON Schema/字段词典和脱敏工单；查证 HTTP 401/403/429、响应分页、超时、tenant 越权等负向路径。
3. **只读实时查询（待审批）**：仅在企业私有网络服务端读取 Vault 临时凭证。实现精确路由/tenant 白名单、限流和缓存；查询结果默认不得出网到外部 LLM，工具只取预算和库存**聚合数**。
4. **客户方案比对（待审批）**：可视化覆盖仍使用批准的离线数据；库存和覆盖逐条对齐并标注来源、快照时间、数据冲突。没有覆盖证据时报告未知，不伪造曝光或空车可售。
5. **Shadow Mode（待审批）**：运行受控只读对照；默认停止所有锁位、审批、自动通知、合同或生产调度写操作。失败可立即回退原 OpenClaw 调度，并提交审计记录。

## 和公网演示严格分离

`deploy/public-demo/` 只运行 `cloud_synthetic` 合成模拟数据，无任何红豆 URL、访问 token、租户 ID、公司网络路由。通过 Caddy HTTPS + 独立访问认证展示客户输入到参考方案；`/api/*`、企业导入/来源同步等高风险入口被拒绝。**这不等于企业生产部署。**
