# CompanyAgent｜问题驱动的可进化企业 Agent 工作台

**INTERCITY HACK 湖州场 · AI+办公 · 上海新云传媒命题 · company Agent 队伍**

**一句话：**员工说出业务问题，Agent 调用可信工具完成媒体推荐和预算规划；每次执行产生证据、质量反馈和可验证的能力迭代。

**业务痛点：**广告销售依赖手工查询商圈覆盖、库存、价格与档期，方案响应慢、调整困难；通用对话 Agent 缺乏可验证的业务工具、权限和进化机制。

**解决方案：**客户行业/品牌/预算/档期输入 → Agent 解析 → 关联授权商圈覆盖与历史库存 → 确定性预算优化 → 风险核验 → 交互式 HTML 提案。员工可自建私有 Agent 和 Skill；平台对缺失证据进行自动诊断，提出改进，进行前后对照，人工批准后发布、可回滚。

**现场演示：**对农夫山泉选择正大广场500米、500万元。初始情景结果13项媒体、其中1项缺商圈证据；改进实验使用相同数据后12项媒体、0项缺证据，并完成发布→重新执行→回滚。另展示100/200/500万元预算调整与员工一键创建 Agent/Skill。

**AI/Agent能力：**自然语言业务需求解析、工具编排、媒体覆盖匹配、报价优化、风险识别、执行轨迹、员工自定义 Agent/Skill、反馈驱动的安全策略迭代；B1X 大模型可选用于文字解释（需配置并经用户确认）。

**数据与安全：**授权的比赛资料，历史公交台账431条、三商圈44条覆盖记录、脱敏刊例价。仅使用赛事许可账号与文件，不抓其他企业系统；公开源代码包不包含这些资料。2027档期库存、正式报价、地铁可售点位、实际客流和ROI均需业务方复核。

**技术：**FastAPI、SQLite、HTML/CSS/JS、业务白名单工具、策略版本与审计。当前为本地单组织 MVP；**Pi Runtime 尚未集成，规则优化不保证全局最优**。

**团队分工：**按实际成员与职责补充，不虚构参与人员。
