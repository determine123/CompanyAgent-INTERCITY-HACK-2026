## 哪些能力已验证，哪些没有

**已验证：** Excel 业务字段与记录数、单日容量分解、分级/媒体形式统计、区间价格口径、双区段 CSV 解析与汇总、三商圈覆盖严格匹配。

**未验证：** 2027-05-01 至 05-28 的公交和地铁库存、合同/预定/维护对目标日期的占用、真实 API 网络访问、库存锁位、正式合同价格、真实覆盖人流、财务 ROI。

特别注意：CSV 中的 **7 条地铁是空间覆盖记录，不是 7 个可出售地铁点位。** 公开 /judge/ 网页目前仍使用 80 条完全虚构的数据执行互动演示；不能说网站直接连通了红豆企业真实数据库。

## 隐私、授权和来源可核验性

原始业务脱敏 Excel、CSV、之前清洗的私有库，以及任何账号/令牌 **没有被上传到公开 GitHub**。公开仓库只存匿名聚合统计、源文件 SHA256、业务核验说明和无需私有数据的负向测试。机器可读审计结果见 docs/evidence/DEIDENTIFIED_HISTORICAL_20261122.json。

原始 2026-11-13 XLSX 的 SHA256 及覆盖 CSV 的指纹可以由数据所有者在私有环境独立对账；并且明确区分用户提供来源与第三方已认证来源。
