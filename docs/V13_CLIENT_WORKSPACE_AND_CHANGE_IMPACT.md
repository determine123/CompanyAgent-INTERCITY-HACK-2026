# CompanyAgent v1.3 · 客户 Brief → Agent 方案 → 排期变更影响

INTERCITY HACK 湖州场 · AI+办公赛道 · 上海新云传媒场景。

## 业务来源与目标

赛事目标：从客户所在行业、预算（100/200/500 万元）、公交/地铁媒体和 2027 投放档期，生成可供评委调整的 HTML 投放候选方案。需通过红豆系统的已授权库存和新云大数据平台的覆盖证据解释推荐，不能把历史参考快照当成已锁定库存。

现场案例图片强调：**要接住的不是排期，是变更。** 客户改稿、车辆换线/进保、城市管制、外包返工、监拍雨天会影响多张业务表，不能只重新打印排期单。本版把它实现成只读、可审计的影响分析与责任清单。

## 已完成的应用闭环

1. 企业工作台的「客户需求与方案」页面（`/enterprise/`），员工选择可访问 Agent，输入 Brief、五种行业、品牌、100/200/500 万预算、2027 日期、投放周期、地标和媒介。
2. 调用现有 `POST /enterprise/api/runs`：使用当前用户有读取权限的库存快照和覆盖记录，生成候选媒体、预算分配、来源及质量门禁；保留完整 Run 记录与原有 Skill 权限。
3. 客户端显示媒体清单、参考金额、覆盖证据百分比和待核验项，可跳到完整执行轨迹、导出单文件交互式 HTML。
4. 新接口 `POST /enterprise/api/runs/{run_id}/change-impact` 支持六种变化：客户改稿、车辆换线、车辆进保、城市管制、外包返工、监拍雨天。输出影响表单、责任岗位、先后依赖（必须先核实来源和资源，再排期/制作/施工，最后客户重新确认）及通知草稿。
5. B1X Tool Calling 使用 v1.2 的 `POST /enterprise/api/runs/{run_id}/model-tools`：每次单独确认，仅三个白名单聚合只读工具，至多四轮，不把客户 Brief 和库存明细发送到模型。未配置 `B1X_API_KEY` 时明确返回失败，不作虚假在线模型成功声明。
6. Data Hub 保留红豆授权 CSV/XLSX 与新云覆盖 CSV/XLSX 导入与严格匹配。红豆网页版及验证码不属于直接 API 连接器；要实现实时查询，必须取得企业批准的 API 或同步导出。

## 排期变更分析的数据边界

- 分析输出 `needs_human_review`，步骤为 `requires_human_confirmation`。
- 无论哪种变化，都返回 `real_system_mutated=false`、`inventory_reserved=false`、`customer_notified=false`。
- 不预测未知车牌、具体替代台数、安装队真实班次、价格变化或施工资源。
- 若缺目标商圈、2027 连续可售档期证据或制作商确认，显式标记证据缺口。
- 原任务记录和预算方案绝不因“影响分析”直接修改；新方案应在核验后另行执行并获得演示审批。
- 目前的工具自动编排仍然是确定性工具执行与证据校验，**不是已经实现 Pi Runtime 自主规划**。排期任务也只是待审核协同建议，不是执行完成证明。

## 本地测试与真实密钥说明

在 Python 3.11+：

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m compileall -q server.py enterprise src
node --check enterprise_web/app.js
node --check web/app.js
```

本地结果：**71/71 pytest**，6 种变更类型、非法日期/工具、权限隔离、无副作用、CSRF 等均覆盖；Chromium 中通过登录、客户 200→100 万预算重新执行、车辆换线影响六步任务、单文件 HTML 服务端导出及移动端 UI，0 JS pageerror。

当前提供的运行环境里 `B1X_API_KEY` **未设置**：只能声称使用 MockTransport 验证 Chat Completions 协议与拒绝越权工具行为，**不能声称已完成真实 B1X 网络联调**。用户可在自己授权电脑的服务端环境配置密钥，并在 UI 单次明确确认后调用：禁止把密钥写进仓库、截图或用户聊天消息。

## 实际演示步骤

打开 `/enterprise/` → 登录 → 「客户需求与方案」 → 选客户与 200 万预算 → 点击「Agent 生成可验证方案」 → 检查覆盖与报价局限 → 修改预算至 100 万重新执行 → 下方选择「车辆换线」→ 查看影响的车线、排期、制作单、施工计划和客户通知 → 导出交互式 HTML → 到「自我迭代实验室」展示从失败到 Skill 对照实验、审批和回滚。

## 数据安全及知识产权

公开源码只包含**虚构演示资源**；比赛的真实系统账号、合同、授权库存与覆盖导出、客户资料、API Key 和运行期数据库不得推送到公开仓库。内部数据导出和截图应使用批准的分享权限。
