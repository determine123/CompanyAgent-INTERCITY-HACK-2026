# CompanyAgent · INTERCITY HACK 2026 提交清单（公开源码版）

比赛：AI+办公（上海新云传媒）｜截止：2026-11-22 12:00 北京时间

## 已包含

- FastAPI + 浏览器工作台，员工个人 Agent 与 Skill 管理（单组织本地 MVP）
- 自动业务工具编排：Brief 解析、覆盖证据匹配、预算约束优化、提案输出
- 反馈收集、受限策略对照实验、人工批准与回滚
- 可公开的虚构媒体库存样例、覆盖与价格导入模板
- README、本地启动脚本、公开版 28 项回归测试与 GitHub Actions CI

## 现场演示建议

1. 在 `/enterprise/` 登录后从业务问题创建 Agent 和 Skill。
2. 选择客户行业、品牌、预算和商圈，展示执行轨迹、数据来源与投放组合。
3. 切换 100 / 200 / 500 万元，展示重新计算的结果；解释预算不是简单调整前端数字。
4. 在结果面板展示质量门禁；管理员只批准用于演示的提案。
5. 直接在 `/enterprise/` 点击“下载可交互 HTML 提案”，离线切换 100/200/500 万。
6. 展示员工反馈、同数据对照实验、审批发布以及回滚。

## 未完成、不可夸大

- 本公开包不包含比赛专用参考库存、覆盖 CSV 或合同文件；运行时默认使用虚构示例。
- 尚未验证 2027 年档期实时可售库存、真实地铁库存或正式报价。
- 目前 Agent 采用确定性工具编排而非 Pi SDK 完整自主规划。
- 红豆与可视化平台网页账号登录不等于存在获授权的实时 API；请勿绕过验证码抓取。
- 本地演示不是公网部署，也不代表已完成 B1X 比赛提交。
