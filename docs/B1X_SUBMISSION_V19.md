## 作品标题

**CompanyAgent｜从客户需求到可审核媒体提案的企业 Agent 工作台**

## 作品简介（500 字内，可直接复制）

面向新云传媒户外广告销售与运营的真实痛点：新销售难以快速理解客户生意目标，媒介库存、覆盖和价格信息分散；客户临时改预算或素材时，提案与执行计划需要反复返工。CompanyAgent 聚焦食品饮料行业，将客户需求结构化为七要素 Campaign 假设书；通过授权数据和受限业务工具生成可解释的公交车身／地铁出入口组合，支持 100／200／500 万元预算在同一冻结数据上即时重算、媒体增减差异展示、离线交互 HTML 提案与执行风险交接。系统带有证据缺口提示、审批、变更影响链与可审计复核。Railway 公网演示使用完全虚构库存，**不声称 2027 档期真实可售或合同报价**；红豆真实库存只读接口等待企业审批后在私有环境试点。目标是缩短售前提案与跨部门沟通时间、减少返工，实际节省须由企业 A/B 工作量验证。

## 现场演示顺序（控制在 90 秒内）

1. 痛点：销售收到模糊需求，“客户今天要方案，明天预算可能翻倍”。
2. 写出“客户生意目标 / 到店 / 人群 / KPI / 监测方式”，显示七要素 7/7 已填但待客户确认。
3. 点“Agent 生成可验证方案”，看选择媒介、预算约束、数据来源/待核验。
4. 导出 HTML，现场从 200 万切到 100 万／500 万，展示组合变化、不是金额等比例缩放。
5. 展示运营核验清单：2027 库存、夜间施工/雨天缓冲、上下刊照片/结案、合同赔补。
6. 展示客户改稿产生的任务依赖链，不直接执行真实写操作。
7. 结尾：可衡量“提案人时、预算返工率、执行漏项”，**尚未有企业实测 ROI，不编造降本比例**。
